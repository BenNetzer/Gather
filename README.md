# Gather

**Gather** היא אפליקציית ווב בעברית, מותאמת קודם כל לנייד, שמרכזת אירועי תרבות ופנאי בירושלים לגילי 20 עד 35. האירועים מוצגים ברשימה ועל מפה, ואפשר לסנן אותם. כל אחד יכול גם להעלות אירוע פרטי, שמתפרסם באתר אחרי אישור של חבר צוות.

הפרויקט נבנה במסגרת קורס "נתונים וטכנולוגיה בעסקים", כ-MVP.

## מה יש באפליקציה

- **רשימה ומפה:** אירועים קרובים מוצגים ברשימה ועל מפת Leaflet, עם סינון לפי תאריך ותג "חינם" לאירועים ללא תשלום.
- **דף אירוע:** כותרת, מועד, מקום, מחיר, קישור למקור וקישור לתשלום כשיש.
- **העלאת אירוע פרטי:** טופס ששומר את האירוע כטיוטה (`draft`). חבר צוות מאשר אותו ב-Supabase, ורק אז הוא מופיע באתר.
- **איסוף אוטומטי:** pipeline שאוסף אירועים ממקורות ציבוריים, מאמת אותם מול טקסט המקור, מסיר כפילויות ומפרסם.

## טכנולוגיות

- **צד לקוח:** HTML, CSS ו-JavaScript רגילים, בלי שלב build, בלי npm ובלי framework. האתר בעברית ובכיוון RTL.
- **מפות:** Leaflet מ-CDN.
- **שרת:** Supabase בחבילה החינמית, דרך ה-REST API (PostgREST) ישירות מהדפדפן, עם Row Level Security.
- **Pipeline:** Python עם הספרייה הסטנדרטית בלבד.

## הרצה מקומית

```bash
python -m http.server 8765 --directory gather
```

אחר כך פותחים את <http://localhost:8765>. פתיחה של `index.html` ישירות מהדיסק (`file://`) לא תעבוד.

כש-`gather/js/config.js` ריק, האתר רץ ב**מצב הדגמה**: הוא קורא את האירועים מ-`gather/data/events.json`, ולא צריך חשבון Supabase. ההוראות לחיבור Supabase, לאישור אירועים ולהרצת ה-pipeline נמצאות ב-[`gather/README.md`](gather/README.md).

## אבטחה

- המפתח הציבורי (anon) יכול לקרוא רק אירועים פעילים, ואף פעם לא את פרטי הקשר של מי שהעלה אירוע.
- המפתח הציבורי יכול להוסיף רק טיוטות פרטיות. אין לו הרשאה לערוך או למחוק.
- מפתח ה-`service_role` משמש רק את `pipeline/publish.py` מהמחשב המקומי. **אסור** להכניס אותו לריפו או לקבצים שהאתר מגיש.

## ענפים

- `main` - הגרסה היציבה.
- `dev` - עבודה שוטפת. שינויים עוברים ל-`main` אחרי בדיקה.
